# SQL Music Store Analysis

## Project Overview
This repository contains a comprehensive SQL analysis of a music store database. The project demonstrates my SQL proficiency, data analysis capabilities, and problem-solving approach when working with relational databases.

## Dataset
The analysis is based on a music store database with the following schema:

- **Customer information**: Demographics and contact details
- **Invoice and billing data**: Purchase history and transaction details
- **Product catalog**: Music tracks, albums, and artists
- **Employee information**: Sales staff data and reporting structure

## Database and Tools
* Postgre SQL
* PgAdmin4

## Key Questions Explored

Through SQL queries, this project answers important business questions such as:

1. Who are our top customers by purchase value?
2. What are the most popular music genres across different countries?
3. How do sales performance metrics vary across employees?
4. What are the revenue trends over time?
5. Which artists generate the most revenue?

## Technical Skills Demonstrated

- **SQL Query Optimization**: Efficient joins and subqueries
- **Aggregate Functions**: Using SUM, AVG, COUNT for data summarization
- **Window Functions**: Analyzing data across partitions
- **Common Table Expressions (CTEs)**: Breaking down complex queries 
- **Data Filtering**: Using WHERE and HAVING clauses effectively
- **Result Set Manipulation**: ORDER BY and GROUP BY operations
- **Data Visualization Preparation**: Structured outputs ready for visualization

## Key Insights

The analysis revealed several actionable insights:

- Customer purchasing patterns show a strong correlation with genre preferences
- Revenue generation is concentrated in specific geographic regions
- Certain product combinations frequently appear in the same transaction
- Seasonal trends affect sales performance across all product categories
